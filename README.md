# Web Terminal Project

## Overview
This is a web based terminal interface built with Python and HTML
The system allows executing shell commands directly through a browser
It features a dark theme with white text for a natural terminal experience

## Installation
Ensure Python is installed on your system
Install Flask using pip if not already present
Navigate to the project directory
Run the application using the command python3 app py
The server will start on port 8066

## Usage
Open your web browser and go to http localhost 8066
Type any command in the input field and press enter
The output will be displayed in the terminal body area
